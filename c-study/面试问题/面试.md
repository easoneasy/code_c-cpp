#### 空类里面有什么？
```
空类的大小是1，是编译器补出来的1字节
有虚函数的话，对象中会多一个虚函数表指针vptr
只有静态成员，对象大小也是1，因为静态成员不属于对象，存放在全局静态区
只有成员函数，对象大小也是1，成员函数不在对象内部，函数代码放在代码段
```

```
C++规定每个对象都必须拥有独立的内存地址
不同对象必须具有不同地址
```

##### inline
什么是inline？ 
```
inline 是一种编译优化机制。

编译器会在调用处直接展开函数体(复制粘贴函数体)
从而减少函数调用开销。

在头文件中写inline
允许函数定义出现在多个cpp中，不会重复定义
```
inline有什么作用？
```
减少 call/ret 带来的函数调用开销，
适合小函数和高频函数。
只是建议，真正的决定权在于编辑器
```
为什么 virtual 通常不能 inline？
```
因为 virtual 函数采用动态绑定，
编译阶段无法确定真正调用哪个函数，
因此通常无法直接展开。
inline要求编译阶段知道调用谁。
```
在工作中的真实应用
STL源码中有些函数使用得很高频。游戏引擎数学计算极高频有大量inline。高性能服务器很多都有inline，可以减少函数跳转成本。模板库，模板函数几乎都在头文件中std::map、std::vector


空指针和野指针的区别？
空指针：主动指向已知状态的指针
	被明确赋值为空NULL的指针，不指向任何有效的内存单元
	空指针的值是0，系统明确禁止程序访问0地址
	解引用程序就会立即崩溃，触发段错误
	用途：指针初始化，条件判断，作为函数失败的返回值
	产生：开发者为了安全故意设置
野指针：未知且不可控的危险指针
	指向一个未知/无效内存地址的指针
	指针指向的内存可能被释放了，或没有被合理初始化
	产生：指针定义后未初始化
		指针释放后未悬空
		指针指向了函数内部的局部变量
