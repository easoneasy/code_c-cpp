
### 说一说strcpy、sprintf与memcpy这三个函数的不同之处

- **`memcpy`**：最底层，只关心**字节**，不关心数据的内容，是最通用、最快的内存复制工具。可以复制二进制数据。
- **`strcpy`**：建立在 C 字符串约定（以 `'\0'` 结尾）之上，只负责**字符串复制**，不需要调用者传长度。
- **`sprintf`**：建立在格式化输出机制之上，负责把**各种类型的数据（整数、浮点数、字符串等）转换并组织成一个字符串**。

它们不是功能重复，而是分别解决了 **内存操作**、**字符串操作** 和 **字符串构造** 三类完全不同的问题

memcpy内存重叠问题
```
复制的方向是从低地址->高地址
如果目标地址在低地址，源地址在高地址，不会出粗
如果目标地址在高地址，源地址在低地址，会产生内存重叠问题，也就是在拷贝的过程中会覆盖掉后面的数据，造成数据重复。造成未定义行为
 
- 比如 a b c d e f 
源地址是a，目标地址是c
复制的时候，将a复制到c的位置，b复制到d的位置，复制原来的c时，已经被改成了a，就会造成内存重叠

解决方法：使用memmove
底层会判断源地址和目标地址的高低大小
如果源地址低于目标地址，就会从后向前（高->低）复制
如果源地址高于目标地址就会从低->高复制
```

memcpy比strcpy效率更高
```
strcpy遇到\0结束，所以在复制的时候会先判断某个字符是否为\0
而memcpy是直接复制指定的长度不会判断，所以效率更高一点
```

memcpy 只适用于平凡可复制（Trivially Copyable）类型，不应直接用于管理资源的复杂类对象
```
如果一个类型是“平凡可复制”的
把它的内存字节原封不动地拷贝到另一块地方，新拷贝出来的数据依然是一个完全合法、可正常使用的对象
没有自定义的拷贝/移动逻辑
没有自定义的析构函数
没有多态

所有的基本数据类型（int, float, char, 指针等）
传统的 C 语言结构体（POD，Plain Old Data），里面只包含基本类型或数组

如果管理资源的复杂类对象
memcpy只会拷贝基本的数据，而不会拷贝行为（拷贝构造函数、析构函数等）
---浅拷贝---
如果一个栈上的指针对象，指向堆上的数据
使用memcpy只能拷贝栈上的指针对象，也指向堆上的数据
如果堆上的数据使用析构函数释放掉了，memcpy拷贝的指针析构的话会造成double free造成内存泄漏

应该使用类的拷贝构造/赋值运算符/移动语义等来进行深拷贝，避免double free
```


### const关键字
const修饰的是 -- 不能通过当前名字修改对象
- const修饰指针
	const指谁谁不动
```
指向常量的指针，Pointer to constant
const int *p
int const *p 
指针指向的数据不能修改，但是可以修改指针的指向

指针常量 Constant pointer
int * const p 
指针的指向不能修改，可以修改指针指向的内容

const int * const p 
既不可以修改指向也不能修改指向的内容
```

- const修饰引用
```
不拷贝对象
保证函数不会修改对象
void print(const string &s)
```

- const修饰成员函数
```
const成员函数不能修改成员变量
成员函数中原本的this指针是  int *const this 
不能修改this指向

成员函数加了const之后，变成了双重const
void func(const int *const this);
既不可以修改指针本身也不能修改当前对象

但是const修饰的成员函数可以修改mutable修饰的成员变量，不受const限制

const重载，有成员函数没有const修饰，和有const修饰
根据调用对象是不是const来选择

普通对象可以调用普通函数，也可以调用const修饰的成员函数
是因为 普通对象的this指针，可以类型转换，
int *const this  -> 可以转换成 int * / const int *
所以const和非const都可以调用，但一般会优先调用非const，不用转换类型

const对象只能调用const修饰的成员函数
```

### static关键字
static改变的是生命周期、作用域、成员归属

- static修饰局部变量
```
存放于静态区，只初始化一次
整个程序结束才释放
```

- static修饰全局变量
```
只能在当前文件中访问
不能 extern
```

- static 修饰函数
```
作用域也只是当前文件
属于内部链接
```

- static成员变量
```
属于整个类，而不是某个对象
```

- static成员函数
```
不能通过  对象.  来访问
是因为没有this指针
所以不能访问普通成员，只能访问static成员
```
