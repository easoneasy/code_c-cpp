# C++ 继承、多态、虚函数、虚继承

---

# 一、继承（Inheritance）

## 1.1 什么是继承

继承是类型之间的关系。

本质：

```text
子类拥有父类的成员
子类对象中包含一个父类子对象
```

例如：

```cpp
class Base
{
public:
    int _base;
};

class Derived : public Base
{
public:
    int _derived;
};
```

对象模型：

```text
Derived对象：

+----------------+
| Base::_base    |
+----------------+
| _derived       |
+----------------+
```

即：

```text
Derived = Base + 自己新增成员
```

继承的作用：

```text
1. 代码复用
2. 建立类型体系
```

---

# 二、虚函数（Virtual Function）

## 2.1 静态绑定

普通成员函数：

```cpp
class Animal
{
public:
    void speak()
    {
        cout << "Animal" << endl;
    }
};
```

调用：

```cpp
Animal *p = new Animal;
p->speak();
```

编译期间已经确定调用：

```cpp
Animal::speak()
```

这种方式称为：

```text
静态绑定（Static Binding）
```

---

## 2.2 virtual

```cpp
class Animal
{
public:
    virtual void speak()
    {
        cout << "Animal" << endl;
    }
};
```

virtual告诉编译器：

```text
该函数需要运行时动态绑定
```

---

# 三、vptr 与 vtable

## 3.1 vtable（虚函数表）

每个含有虚函数的类都有自己的虚函数表。

作用：

```text
保存虚函数入口地址
```

例如：

```cpp
class Animal
{
public:
    virtual void speak(){}

    int age;
};
```

对象：

```text
Animal对象：

┌────────────┐
│ vptr       │
├────────────┤
│ age        │
└────────────┘
```

对应：

```text
Animal vtable

┌────────────────┐
│ Animal::speak  │
└────────────────┘
```

---

## 3.2 vptr（虚函数指针）

每个对象都有自己的vptr。

作用：

```text
指向所属类的vtable
```

构造对象时：

```cpp
a.vptr = &Animal_vtable;
```

注意：

```text
一个类一个vtable
一个对象一个vptr
```

---

# 四、多态（Polymorphism）

## 4.1 什么是多态

多态：

```text
父类指针/引用
调用子类重写后的虚函数
```

本质：

```text
运行时动态绑定
```

---

## 4.2 多态三要素

必须同时满足：

```text
1. 继承
2. 虚函数
3. 父类指针或父类引用
```

例如：

```cpp
class Animal
{
public:
    virtual void speak()
    {
        cout << "Animal" << endl;
    }
};

class Dog : public Animal
{
public:
    void speak() override
    {
        cout << "Dog" << endl;
    }
};
```

调用：

```cpp
Animal *p = new Dog;

p->speak();
```

输出：

```text
Dog
```

---

## 4.3 多态执行过程

```cpp
Animal *p = new Dog;

p->speak();
```

执行过程：

```text
1. 找对象中的vptr
2. 找到Dog的vtable
3. 找到Dog::speak地址
4. 调用Dog::speak
```

本质：

```text
对象
→ vptr
→ vtable
→ 函数地址
```

---

## 4.4 override

```cpp
void speak() override;
```

作用：

```text
检查是否真正重写父类虚函数
```

避免函数签名写错。

---

## 4.5 final

禁止继承：

```cpp
class Base final
{
};
```

禁止重写：

```cpp
virtual void func() final;
```

# 六、虚析构函数

## 6.1 为什么析构函数必须virtual

错误写法：

```cpp
class Base
{
public:
    ~Base(){}
};

class Derived : public Base
{
public:
    ~Derived(){}
};
```

调用：

```cpp
Base *p = new Derived;

delete p;
```

结果：

```text
只调用Base析构函数
不会调用Derived析构函数
```

可能导致资源泄漏。

---

## 6.2 正确写法

```cpp
class Base
{
public:
    virtual ~Base(){}
};
```

执行：

```text
Derived::~Derived()
↓

Base::~Base()
```

原则：

```text
只要类准备被继承
并且可能通过父类指针释放对象

析构函数必须virtual
```

# 八、菱形继承

## 8.1 菱形继承问题

```cpp
class Animal
{
public:
    int age;
};

class Mammal : public Animal
{
};

class Bird : public Animal
{
};

class Bat : public Mammal, public Bird
{
};
```

结构：

```text
         Animal
         /    \
        /      \
   Mammal      Bird
        \      /
         \    /
           Bat
```

---

## 8.2 问题

Bat对象中存在：

```text
两份Animal
```

即：

```text
Mammal::Animal
Bird::Animal
```

导致：

```text
1. 数据冗余
2. 二义性
```

例如：

```cpp
Bat b;

b.age;
```

编译器不知道访问哪份Animal。

---

# 九、虚继承（Virtual Inheritance）

## 9.1 解决方案

```cpp
class Mammal : virtual public Animal
{
};

class Bird : virtual public Animal
{
};
```

作用：

```text
整个Bat对象中只保留一份Animal
```

---

## 9.2 对象模型

```text
Bat对象：

┌────────────────┐
│ Mammal部分     │
│ vbptr          │
├────────────────┤
│ Bird部分       │
│ vbptr          │
├────────────────┤
│ 共享Animal     │
│ age            │
└────────────────┘
```

---

## 9.3 vbptr

Virtual Base Pointer

虚基指针。

作用：

```text
指向vbtable
```

---

## 9.4 vbtable

Virtual Base Table

虚基表。

作用：

```text
保存虚基类偏移量
```

本质：

```text
偏移量数组
```

例如：

```text
vbtable

┌────────────┐
│ offset(A) │
└────────────┘
```

---

## 9.5 查找虚基类过程

访问：

```cpp
obj.age;
```

执行过程：

```text
1. 找obj.vbptr

2. 找vbtable

3. 找到Animal偏移量

4. obj地址 + offset

5. 找到Animal子对象
```

---

## 9.6 为什么需要vbtable

普通继承：

```text
父类位置固定
```

虚继承：

```text
虚基类位置由最终派生类决定
```

例如：

```text
Bat决定Animal放在哪里
```

因此：

```text
Mammal和Bird无法提前知道
Animal的位置
```

只能：

```text
vbptr
→ vbtable
→ offset
```

动态定位。

# 十一、面试总结

继承：

```text
子类对象包含父类子对象
实现代码复用和类型体系
```

多态：

```text
继承 + 虚函数 + 父类指针/引用

实现运行时动态绑定
```

虚函数机制：

```text
对象
→ vptr
→ vtable
→ 函数地址
```

虚继承机制：

```text
对象
→ vbptr
→ vbtable
→ offset
→ 虚基类地址
```

多态的价值：

```text
调用方依赖抽象接口
不依赖具体实现

实现解耦和扩展性
```
