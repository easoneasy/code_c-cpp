##### vim设置.c文件模板
```shell
sudo vim  ~/.vim/plugged/prepare-code/snippet/snippet.c
```

##### 公共头文件
Linux系统存放系统头文件的目录是`/usr/include`，我们可以使用sudo权限在该目录下新建一个头文件
`my_header.h`   
其他用户也要加上写权限


##### vim设置.cpp/cc文件模板
`cd ~/.vim/plugged/prepare-code/snippet`
`vim snippet.cpp`

##### 在vim内启用鼠标
编辑.vimrc文件
写入：`set mouse = a`

##### 在vscode配置c++模板
![[vscode_配置模板1.png]]
![[vscode_配置模板2.png]]

在cpp.json中添加如下：
```c++
"Print to conaole":{

    "prefix": "C++",    //在新建立的页面中输入C++就会有智能提示，Tab就自动生成好了
    "body": [
        "#include <iostream>",
        "", //空行
        "using namespace std;", //标准命名空间
        "",
        "void test1()",
        "{",
        "",
        "",
        "}",
        "int main(int argc,char *argv[])",   //main()函数
        "{",
        "   $0",    //最终光标会在这里等待输入
        "   test1();",    //标准C++的等待用户动作
        "   return 0;", //结束
        "}",
        "",
    ],
    "description": "A cpp file template."   //用户输入后智能提示的内容（你可以用中文写“生成C++模板”）
}
```
