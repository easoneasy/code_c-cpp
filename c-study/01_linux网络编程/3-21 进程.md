ps -elf 一般查看
S：进程的状态，R是运行、S睡眠、Z僵尸进程
PID：进程id，唯一标识进程
PPID：进程的父进程的id
C：cpu的占用率
PRI：进程的优先级
NI：控制nice值，与优先级相关。数越小，优先级越高
STIME：程序运行的开始时间
TIME ：花费的CPU时间
CMD：启动进程的命令

ps aux 查看cpu、内存的占用情况
PID：进程id
%CPU：CPU的占用
%MEM：内存的占用
RSS：实际占用的内存大小
START：进程开始时间
COMMAND：启动的命令

==fork==
创建子进程，
没有入参，返回值是pid_t, 看返回值ret 来确定当前是在父进程中还是子进程中
	负数：调用函数失败
	0：表明当前是在子进程中
	正数：当前在父进程中，ret的值是子进程的pid
```c
pid_t fork(void);
```
创建一个子进程，fork以下的代码，父进程、子进程都要执行
```c
printf("fork before.\n");  // \n一定要加
pid_t ret =fork();
printf("fork after.\n");   //这里有两个进程执行，会打印两次
```

```c
printf("fork before.\n");  // \n一定要加
pid_t ret =fork();
printf("fork after.\n"); 
pid_t ret =fork();
printf("fork after.\n"); 
//分别打印1、2、4次
```

查看fork的返回值
	负数：调用函数失败
	0：表明当前是在子进程中
	正数：当前在父进程中，ret的值是子进程的pid


内存是隔开的，
父进程改局部变量子进程看不到
子进程改局部变量父进程看不到

fork的内存可以简单认为是复制，实际实现的时候不是直接复制
采取的是写时复制  COW copy on write
(写入的时候复制某个写入的变量所占据的物理内存（以页为单位复制）)

在fork之前打开文件，父进程、子进程写入文件
文件中全部显示父进程和子进程写入的内容

子进程会拷贝父进程的文件描述符数组（其中存储的指向一个文件表项的指针。）
这个文件表项是操作系统维护的可以多个进程共享。维护了inode指针和文件读写位置的偏移量。

父进程和子进程将共享打开的文件表项。父子进程对同一个文件对象共享读写位置
```c
int fd = open("file_before", O_RDWR);
pid_t pid = fork();
if(pid == 0){
    write(fd, "hello", 5);
    sleep(1);
    write(fd, "world", 5);
}else{
    write(fd, "nothing", 7);
    sleep(1);
    write(fd, "happen", 6);
}
-->输出 nothinghellohappenworld
```

在fork之后，分别在父进程、子进程里打开文件并写入文件
操作系统会创建两个不同的文件表项，各种独立维护偏移量，但是进入到同一个文件中去
父进程、子进程对同一个文件不会共享读写位置
![[fork父子进程都打开同一个文件.png]]
```c
int main(){
    pid_t pid = fork();
    if(pid == 0){
        int fd = open("file_after", O_RDWR);
        write(fd, "hello", 5);
        sleep(1);
        write(fd, "world", 5);
    }else{
        int fd = open("file_after", O_RDWR);
        write(fd, "nothing", 7);
        sleep(1);
        write(fd, "happen", 6);
    }
    return 0;
}
-->helloworldpen
```
