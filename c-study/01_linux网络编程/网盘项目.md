##### strtok的问题
`strtok` 在寻找第一个token的时候，会自动跳过字符串开头的所有分隔符
- 比如 字符串是 `///a/b` 第一次`strtok(str,"/");`返回的就是“a”
`strtok` 会修改原字符串，将`/` 改成`\0`
- 最好使用strtok的返回值（指针）来操作字符串
```c
    char ab_str[20]="/1/2/3/4";
	//第一次分割
    char *ap=strtok(ab_str,"/");
    printf("ab_first %s \n",ap);
    //其他几次分割
    while((ap=strtok(NULL,"/"))){
        printf("while ab %s\n",ap);
    }
```

##### mysql 返回值的问题
`mysql_query`
- 返回值0，表示sql指令已成功发送并被服务器执行
- 非0，表示执行失败

`mysql_store_result`
- `res != NULL`: 查询成功，且有结果集（即便行数为 0）。
- `res == NULL` 且 `mysql_field_count(conn) > 0`: 发生了致命错误。
- `res == NULL` 且 `mysql_field_count(conn) == 0`: 属于正常的写操作（DML 增删改）。

扩展：
**`mysql_store_result`   vs   `mysql_use_result`**:
- `store`: 优点是支持 `mysql_num_rows` 预知行数，缺点是如果数据量大（如 1G），会导致客户端 OOM。
- `use`: 不会立刻下载数据，而是 `mysql_fetch_row` 调用一次下载一次。优点是省内存，缺点是会长时间锁定服务端表资源，且不支持随机跳转指针。
```c
MYSQL_RES *res = mysql_store_result(conn); 
if (res == NULL) { 
// mysql_store_result 返回 NULL 有两种可能： 
// A. 该 SQL 本就不该有返回值 (如 UPDATE/INSERT) 
// B. 发生了错误 (如内存不足、连接中断) 
if (mysql_field_count(conn) == 0) { 
// 情况 A：非查询语句，获取受影响行数 
	printf("Success: %llu rows affected\n",mysql_affected_rows(conn)); 
} else { 
// 情况 B：查询失败 
	fprintf(stderr, "Store Result Error [%u]: %s\n",mysql_errno(conn), mysql_error(conn)); 
} 
	return; 
}
```

###### 获取结果集的行数
`mysql_num_rows(result)`
返回结果集中的查询到的记录总数（行数）
-  如果等于 `0`：表示数据库里没有任何一条记录符合搜索条件
- 如果大于 `0`：表示有数据

`row = mysql_fetch_row(result)`
尝试从结果集中取出一行，并告诉你是否成功
是为了**拿数据**而存在的
`mysql_fetch_row`每次被调用时就会从结果集中抓取下一条数据，如果没有数据或已经取完了，就会返回NULL
- 如果是**第一次**调用就返回 `NULL`：说明结果集本来就是空的（效果等同于 `num_rows == 0`）
- 如果是在循环中途返回 `NULL`：说明数据已经取完了。
- 考点：返回的是字符串，即使数据库中是int，也会返回字符串

`mysql_insert_id(MYSQL *conn)`
仅在表中有 `AUTO_INCREMENT` 列时有效
返回值类型是 my_ulonglong (unsigned long long)
如果返回值=0，说明表里没有自增字段或插入失败
`mysql_query` 返回 0 后，立即调用 `mysql_insert_id(conn)`
- **原理**：该函数直接从 MySQL 连接协议的 OK 报文中读取服务端返回的 `insert_id`，不经过磁盘查询，效率极高。
- **并发安全**：它是基于**连接**的。即使多个客户端同时插入数据，它也只会返回**当前连接**最后一次生成的 ID，不会被其他人的操作干扰。

##### 将路径分离成单个文件/目录
将字符串放入数组中，for循环遍历数组，碰到有/就改成\0，得到一段路径
写一个指针指向这块字符串
`备份、截断、查数据，还原、跳步、找下级`

```c
#include <stdio.h>
#include <string.h>
/**
 * 模板说明：
 * 1. 使用临时缓冲区，保护原始路径不被修改。
 * 2. 自动处理开头的 '/'、中间连续的 '//' 以及结尾的 '/'。
 * 3. 逻辑闭环，无需在循环外写多余的“补丁”代码。
 */
int path_parser_template(const char *path) {
    // --- 1. 准备阶段 ---
    char buf[1024] = {0};
    strncpy(buf, path, sizeof(buf) - 1);

    char *start = buf;       // 指向当前层级的开头
    int len = strlen(buf);
    int current_id = 1;      // 假设根目录 ID 为 1（业务逻辑起点）

    // --- 2. 核心循环：注意 i <= len，必须包含字符串结束符 ---
    for (int i = 0; i <= len; i++) {
        // 遇到 '/' 或者字符串末尾 '\0' 时，说明找到了一个层级
        if (buf[i] == '/' || buf[i] == '\0') {
            char backup = buf[i]; // 1. 备份当前位置的字符
            buf[i] = '\0';        // 2. 将当前位置设为结束符，实现“临时切分”

            // 3. 业务逻辑区：过滤空字符串（防止处理 "a//b" 这种路径）
            if (*start != '\0') {
            
            }

            buf[i] = backup;      // 4. 还原字符（把刚才的 \0 变回 / 或 \0）
            start = &buf[i + 1];  // 5. 将 start 移动到下一个层级的起点
        }
    }

    return 0;
}
```

##### 数据库表的级联删除
比如要删除一个文件夹，可以删除此文件夹下所有的文件（包括文件和目录）
使用递归很麻烦，但是可以用mysql8.0以上的级联

先看数据库表中有无没有关联父目录id的表项
```sql
SELECT * FROM file_info 
WHERE parent_id IS NOT NULL 
AND parent_id NOT IN (SELECT id FROM file_info);
```

如果有数据的话有两种方法：
方法一：删除这些数据
```sql
DELETE FROM file_info 
WHERE parent_id IS NOT NULL 
AND parent_id NOT IN (SELECT id FROM file_info);
```

方法二：把它们的父目录设为 NULL（即把它们变成根目录）
```sql
UPDATE file_info 
SET parent_id = NULL 
WHERE parent_id IS NOT NULL 
AND parent_id NOT IN (SELECT id FROM file_info);
```

然后就可以添加表项
```sql
ALTER TABLE file_info ADD INDEX idx_parent (parent_id);
```

再加外键约束
```sql
ALTER TABLE file_info
ADD CONSTRAINT fk_parent_cascade
FOREIGN KEY (parent_id)
REFERENCES file_info(id)
ON DELETE CASCADE;
```
