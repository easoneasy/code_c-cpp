##### 主键
为了标识一个表中的数据不允许重复，可以使用主键
一个表中主键只能唯一，不能设置两个以上的主键
主键的值不能为空

主键可以是一个字段也可以是多个字段联合在一起设计（联合主键）
创建方式：
```mysql
#创建表的时候直接指定主键
create table 表名 (id int primary key,...);

#在表创建完成之后给表添加主键（改结构，直接使用alter）
create table 表名(id int ,.....);
alter table 表名 add primary key(id);

```


##### 唯一键

添加唯一键（这一列的内容不能重复，但是可以为空）
`alter table 表名 add unique key (列);`

##### 自增问题
`auto_increment`

字段属性设置位`NOT  NULL`

##### 特殊的字段
###### where

范围

枚举

模糊查询：`like`

`_`占位符，只占一位

###### distinct 
在字段显示的时候去重
`select distinct 字段 from 表名`

###### limit
在数据量多的时候只显示固定几行
`select 字段 from 表名 limit M,N`
限制从M开始的N条数据，如果N被省略了就最多显示M条数据
M,N都在，就是从M开始的N条数据，数据都是从0开始算的

###### as
为表和字段指定别名，
`select * from 表名 as 表名别名 where 表名别名.字段 条件`
为了简化操作，比如一个表名比较长，又需要频繁使用可以用别名
在给表或字段取别名的时候as可以省略
`select * from 表名 表名别名 where 表名别名.字段 条件`

###### order by
`asc`  升序 默认
`desc`  降序

###### group by
分组将多条散落的数据合为一条数据
`group by` 之后一个组只显示一条数据

###### 聚集函数
sum求和、avg平均值、min最小值、max最大值、count条数

###### count
count 后＋列，会去掉空值
`count(*)` 会显示全部行
`count(数字)` 会显示全部行
结果与性能基本等价，都是显示表中所有行数（包含空行）

###### having
```mysql
select sum(english) from person group by person_id having sum(english) >=200;
```
过滤，对==分组之后的结果==进行过滤，执行顺序肯定是在group by之后

##### ==SQL的执行顺序==
```mysql
(1)select 
(2)from table_name
(3)where
(4)group by      
#group by 之后就可以用聚集函数
#(select、having之后都可以使用聚集函数)
(5)having
(6)order by
(7)limit

#select 、from 是拿到表，处理原始数据
#3、4、5将原始数据合并得到组的概念
#6对分组之后的结果进行排序，排序可能有多个结果，如果没有分组就只能对原始数据排序
#7对排序之后的显示结果进行选择性显示
```

##### 数据完整性
###### 数据完整性 
确保每条数据是唯一的，使用主键
###### 域完整性
保证表中数据的字段的取值在有效范围之内或者符合特点的数据类型约束
###### 参照完整性
涉及到两张表，通过外键和主键维护
```mysql
constraint   foreignkeyname   foreign key   列    reference   另外一个表的列
```
一个表A的外键关联倒另一个表B的主键，A表在插入数据的时候，外键一定要在B表中，否则就会失败
在删除的时候，直接删除A表中的任何一条是没有关系的，但是如果删除的是B表，那么外键一定不能被A表中的外键关联，否则就删除失败

面试常见的问题：
聚集索引、聚簇索引
同一个东西，从英文翻译过来之后的中文不一样
特点是将数据与索引一起存放（例如：InnoDB）

非聚集索引、非聚簇索引
特点是将数据与索引分开存放（例如：MyISAM）


InnoDB存储引擎，一定需要有索引，所以为了严格标识每一条数据最好可以设置主键索引，如果没有设置，数据库背后会设置一个虚拟索引，也就是6字节的ROW_ID
对于MyISAM引擎而言是可以没有索引的

索引不是越多越好，索引比较占用内存

什么列适合作为索引：
重复度低的列、使用率高的列、该列的值不会频繁发生变化的列

索引在建表的适合创建，一般设置为int，+ auto_increment

回表？怎么避免回表？什么是覆盖索引
使用主键索引查。使用索引覆盖。
使用辅助索引，select查询的时候尽量不使用 `*`

最左匹配原则
组合索引，会涉及到多个列，在查询的时候，要出现最左边的列，如果没有出现就不会用到索引，在最左边的列使用的情况下依次使用后面的列
