[88. 合并两个有序数组](https://leetcode.cn/problems/merge-sorted-array/)

给你两个按 非递减顺序 排列的整数数组 nums1 和 nums2，另有两个整数 m 和 n ，分别表示 nums1 和 nums2 中的元素数目。
请你 合并 nums2 到 nums1 中，使合并后的数组同样按 非递减顺序 排列。
```c
void merge(int* nums1, int nums1Size, int m, int* nums2, int nums2Size, int n) {
    // 指向两个数组最后一个有效元素
    int i = m - 1;
    int j = n - 1;
    // 指向 nums1 最后一个空位
    int k = m + n - 1;
    // 从后往前放更大的数
    while (i >= 0 && j >= 0) {
        if (nums1[i] > nums2[j]) {
            nums1[k--] = nums1[i--];
        } else {
            nums1[k--] = nums2[j--];
        }
    }
    // 如果 nums2 还有剩余，直接复制过去
    while (j >= 0) {
        nums1[k--] = nums2[j--];
    }
}
```


[27. 移除元素](https://leetcode.cn/problems/remove-element/)

给你一个数组 nums 和一个值 val，你需要原地移除所有数值等于 val 的元素。元素的顺序可能发生改变。然后返回 nums 中与 val 不同的元素的数量。

假设 nums 中不等于 val 的元素数量为 k，要通过此题，您需要执行以下操作：
更改 nums 数组，使 nums 的前 k 个元素包含不等于 val 的元素。nums 的其余元素和 nums 的大小并不重要。
返回 k。

```c
int removeElement(int* nums, int numsSize, int val) {
//i是指已经排好的元素
    int i= 0;
//快指针遍历
    for(int j=0;j<numsSize;j++){
//如果不是要删除的元素
        if(nums[j]!=val){
//就把这个元素放在i所指位置，作为排好的元素
            nums[i++]=nums[j];
        }
    }
//i的位置就是去掉val元素的个数
    return i;
}
```


[26. 删除有序数组中的重复项](https://leetcode.cn/problems/remove-duplicates-from-sorted-array/)

给你一个 非严格递增排列 的数组 nums ，请你原地删除重复出现的元素，使每个元素 只出现一次 ，返回删除后数组的新长度。元素的 相对顺序 应该保持 一致 。然后返回 nums 中唯一元素的个数。

考虑 nums 的唯一元素的数量为 k。去重后，返回唯一元素的数量 k。
nums 的前 k 个元素应包含 排序后 的唯一数字。下标 k - 1 之后的剩余元素可以忽略。

```c
int removeDuplicates(int* nums, int numsSize) {
//k指向的是已经排好的元素
        int k = 0;
//快指针j遍历，找到不相同的元素
    for (int j = 0; j < numsSize; j++) {
        if (nums[k] != nums[j]) {
            k++;
            //把不相同的元素放在k的位置
            nums[k] = nums[j];
        }
    }
    //k+1就是去掉重复元素的个数
    return k+1;
}
```

[80. 删除有序数组中的重复项 II](https://leetcode.cn/problems/remove-duplicates-from-sorted-array-ii/)

给你一个有序数组 nums ，请你 原地删除重复出现的元素，使得出现次数超过两次的元素只出现两次 ，返回删除后数组的新长度。
不要使用额外的数组空间，你必须在原地 修改输入数组** 并在使用 O(1) 额外空间的条件下完成。

和26题类似
```c
int removeDuplicates(int* nums, int numsSize) {
//如果数组中只有两个元素，就返回数组的长度
    if (numsSize <= 2) return numsSize;
//i和j从2开始
    int i = 2;
//慢指针i和快指针j
    for (int j = 2; j < numsSize; j++) {
//判断j是否是和i-2、i-1相同，如果相同那么这个元素多于两次
        if (nums[j] != nums[i - 2]) {
//不相同就把j所指元素放入i的位置。i++
            nums[i++] = nums[j];

        }
    }
//最后i的位置就是去掉出现多于2次的长度
    return i;
}
```


[169. 多数元素](https://leetcode.cn/problems/majority-element/)

给定一个大小为 n 的数组 nums ，返回其中的多数元素。多数元素是指在数组中出现次数 大于 ⌊ n/2 ⌋ 的元素。

你可以假设数组是非空的，并且给定的数组总是存在多数元素。

看到 “出现次数> 一半 / 1/3”
直接用：摩尔投票法（时间 O (n)，空间 O (1)，最优解）
对应题目：
超过 n/2 → 1 个候选人
超过 n/3 → 2 个候选人 + 必须验证

相同+1，不同-1
票数变0，需要换人
```c
int majorityElement(int* nums, int numsSize) {

    int candidate = nums[0];  // 候选数字
    int count = 1;           // 票数
    for (int i = 1; i < numsSize; i++) {
        if (nums[i] == candidate) {
            count++;    // 一样，支持
        }
        else {
            count--;    // 不一样，抵消
        }
        // 票数没了，换当前数字当候选人
        if (count == 0) {
            candidate = nums[i];
            count = 1;
        }
    }
    return candidate;  // 最后活下来的就是多数元素
}
```

[229. 多数元素 II](https://leetcode.cn/problems/majority-element-ii/)

给定一个大小为 n 的整数数组，找出其中所有出现超过 ⌊ n/3 ⌋ 次的元素。
```c
int *majorityElement(int *nums, int numsSize, int *returnSize) {
//选出两个候选人
    int candiate1 = nums[0];
    int candiate2 = nums[1];
//票数设为0
    int cnt1 = 0;
    int cnt2 = 0;
//判断票数
    for (int i = 0; i < numsSize; i++) {
        if (nums[i] == candiate1) {
            cnt1++;
        }
        else if (nums[i] == candiate2) {
            cnt2++;
        }
        else if (cnt1 == 0) {
            candiate1 = nums[i];
        }
        else if (cnt2 == 0) {
            candiate2 = nums[i];
        }
        else {
            cnt1--;
            cnt2--;
        }
    }
//验证投票的真伪
//答案一定在候选里，验证的话假答案一定会去掉

//如果数组是1、2、3、4、5
//那么cnt1 = 1；cnt2=2；
//放在验证这里，就会失败，因为候选值要都＞2；cnt1、cnt2不满足条件所以会返回空值
    cnt1 = 0;
    cnt2 = 0;
    for (int i = 0; i < numsSize; i++) {
        if (nums[i] == candiate1) { cnt1++; }
        else if (nums[i] == candiate2) { cnt2++; }
    }
//收集答案，把候选的两个值放入数组中。
//为什么要申请动态空间放数组？
//因为c语言返回值不能返回数组，只能申请动态空间，返回指向这个数组首元素的指针res
//*returnSize传入传出参数，可以从main函数中得到数组的长度
    int *res = (int *)malloc(2 * sizeof(int));
    *returnSize = 0;
    if (cnt1 > numsSize / 3) {
        res[(*returnSize)++] = candiate1;
    }
    if (cnt2 > numsSize / 3) {
        res[(*returnSize)++] = candiate2;
    }
    return res;
}
//申请的动态数组需要在main函数中释放
//因为main函数调用函数需要获取函数的返回值，如果在函数中就把动态数组释放掉，main函数接收的指针就会越界（不是存放的数据）
```
