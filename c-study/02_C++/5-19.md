
左值：有持久身份的对象，**可以取地址**，通常有名字
右值：临时对象，**无法取地址**，生命周期往往只在当前表达式中
什么是右值引用：
**右值引用**，就是专门用来绑定到右值（临时对象）的引用。通过右值引用，我们可以延长临时对象的生命周期。
引用右值引用的原因：防止深拷贝，实现移动语义的，提高性能

移动构造 (为了节约空间、提高效率，防止深拷贝)
移动运算符函数

```c++
//移动构造函数
//处理右值对象/临时对象
//右值引用绑定临时对象
//进行资源转移
String(String &&rhs)
:m_pstr(rhs.m_pstr)  //浅拷贝
{
    cout << "move constructor" << endl;
    //把临时对象的指针设置为空
    rhs.m_pstr = nullptr;
}

//移动赋值运算符函数
//右值引用绑定临时对象
String& operator=(String &&rhs)
{
    cout << "move operator = " << endl;
    //自赋值判断
    if(this != &rhs)
    {
        //回收原本空间
        delete [] m_pstr;
        //深拷贝-->浅拷贝
        //两个指针共享一个空间
        m_pstr = rhs.m_pstr;
        //将临时对象底层的指针设置为空
        rhs.m_pstr = nullptr;
    }
    //返回当前对象 *this
    return *this;
}
```



std::move()
主要做类型转换：把一个左值转换成一个右值
只是类型转换，不涉及资源的转移（取决于移动相关的函数）



##### RAII   
resource acquisition is initialization
资源获取即初始化时机

特点：
	1、创建对象时，托管资源（初始化）
	2、对象销毁时，释放资源
	3、提供若干访问资源的方法
	4、一般要表达对象语义，不能进行复制或赋值（获取的是系统资源
