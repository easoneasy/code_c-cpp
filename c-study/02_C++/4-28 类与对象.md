
面向对象：
	把现实生活的场景，搬到代码中，一一映射
	对象的来源：类---提取共有的属性
自定义类型：属性的集合（数据成员/成员变量）、行为的集合（成员函数）。类中的成员

```c++
class Dog{
public:   //权限修饰符
	//属性的集合
	int age;
	string color;
	string name;
	//行为的集合
	void bark(){
		cout << "wwww" << endl;
	}
};

Dog dog1;  //新建对象
dog1.age = 1;
dog1.name = "萨摩耶";
dog1.color = "白色";
cout << dog1.age << endl;
```
类中的权限修饰符
	public //作用范围，开始写public到 下一个修饰符/类最后  之间
		可以任意访问
	private   
		在类的外部，不能直接访问；类的内部可以访问，默认权限
	protected

###### 封装
通常做法：
	把不想被外界访问的成员使用private修饰
	给外界提供一个访问接口：读写分离操作
		访问需求：提供getxx方法，用于数据的读取
		修改需求：提供setxx方法，用于数据的修改

```c++
class Student{
public:
	int id;
	string name;
	//提供访问的入口 getxxx
	int getScore(){
		return score;
	}
	//提供一个修改的入口
	void setScore(int new_score){
		//对数据校验
		score = new_score;
	}
private:
	int score;
};
```

###### 多态
（重要）
对于同一指令/行为，不同子类表现的行为或形式不同

使用：
	父类型接收子类对象
	通过父类型调用同名的虚函数
	体现出不同子类的行为

##### 类的使用
声明，可以声明多次： class 类名;
定义：class 类名 { 类体  } ;
	
```c++
class 类名 {
//类体
//数据成员--->属性的集合
//成员函数--->行为的集合
};
```

成员函数的声明和实现写一起，默认是内联函数
声明和实现分开写，把具体的代码实现写在外部
```c++
//在类中声明
void func();

//在类外实现，需要使用类名作用域
void MyClass::func(){

}
```

类的分类
简单类、复杂类
简单类：类中的数据成员都是内置类型，不涉及动态分配
复杂类：涉及动态分配
```c++
class Computer
{
public:
	void setBrand(const char *brand){
		//动态分配内存，使用析构函数
		m_brand = new char[strlen(brand)+1]{};
		strcpy(m_brand,brand);
	}
	void setPrice(int price){
		m_price = price;
	}
	void print(){
		cout <<m_brand<<" "<<m_price<<endl;
	}
private:
	char *m_brand;
	int m_price;
}
```

C++中  结构体   vs   类
类中如果没设置权限，默认是private权限
结构体默认是public

C中的struct不能写函数
C++中的struct能写函数，默认权限是public
C++ 中的struct和class的默认权限不一样，其他都一样



##### 命名规范
小驼峰：单个单词小写，多个单词，第一个单词小写，后续单词的首字母大写
student    getMaxValue
大驼峰：单个单词首字母大小，多个单词，第一个单词首字母大写，后续单词的首字母大写
Student   GetMaxValue

程序中的结构命名
变量：小驼峰
常量：全部大写
函数名：小驼峰
类名：大驼峰
