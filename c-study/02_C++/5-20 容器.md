
容器给自定义类型排序的方法
自动排序的容器（关联式容器）
手动排序的容器（序列式容器）

##### 关联式容器给自定义类型排序
set、multiset、map、multimap
特点： 元素在被 insert 扔进容器的瞬间，底层（红黑树）就会自动把它排好序。

这类容器有3种写法：
	默认走重载 <
	或者在初始化时指定自定义的函数对象
	特化`std::less`

重载 < 运算符
```c++
class Person {
public:
    string m_Name;
    int m_Age;
    Person(string name, int age) : m_Name(name), m_Age(age) {}

    // 🌟 核心：必须重载 < 运算符，且必须用 const 修饰
    bool operator<(const Person& p) const {
        // 按照年龄从小到大排序（升序）
        return this->m_Age < p.m_Age; 
    }
};
```

定义函数对象
```c++
struct MyCompare {
    // 🌟 核心：重载 () 运算符，同样必须加 const
    bool operator()(const Person& p1, const Person& p2) const {
        return p1.m_Age > p2.m_Age; // 改变规则：按照年龄降序
    }
};
```

特化`std::less`
```c++
namespace std {
    template <> // 代表这是一个全特化
    struct less<Person> {
        // 重载 () 运算符，规定 Person 的比较规则
        bool operator()(const Person& p1, const Person& p2) const {
            return p1.m_Age < p2.m_Age; // 按照年龄升序排序
        }
    };
}
```


##### 序列式容器给自定义类型排序
vector、deque、list
特点： 它们平时是无序的，你怎么放它就怎么存。需要排序时，得手动调用外部算法或成员函数

###### vector与deque
使用标准库`<algorithm>`的 `std::sort`
```c++
#include <vector>
#include <algorithm>

// 方案 A：写一个全局比较函数
bool comparePerson(const Person& p1, const Person& p2) {
    return p1.m_Age < p2.m_Age;
}

int main() {
    vector<Person> v = { {"张三", 20}, {"李四", 18} };

    // 写法 1：传入全局函数
    sort(v.begin(), v.end(), comparePerson);

    // 写法 2：直接写 Lambda 表达式（现代 C++ 最常用的优雅写法）
    sort(v.begin(), v.end(), [](const Person& p1, const Person& p2) {
        return p1.m_Age < p2.m_Age;
    });
    
    //写法3：在类内重载<
    sort(v.begin(), v.end())
}
```

###### list
是链表，不能用标准的`std::sort`，必须用自己的成员函数
```c++
#include <list>

int main() {
    list<Person> L = { {"张三", 20}, {"李四", 18} };

    // 写法 1：传入全局比较函数
    L.sort(comparePerson);

    // 写法 2：传入 Lambda 表达式
    L.sort([](const Person& p1, const Person& p2) {
        return p1.m_Age < p2.m_Age;
    });
}
```
