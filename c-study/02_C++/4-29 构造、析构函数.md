##### 构造函数
对象一创建就初始化了类中的变量
是类中的特殊成员函数
作用：在对象创建过程中，自动调用
```c++
类名 （形参列表）{
	构造函数体
}

创建对象：
类名 对象名(传入的参数)/{ }
//()或{} 都可以
```

**没有返回值**
函数名必须和类名一样
形参列表和普通函数一样
无参：无参构造函数
	无参构造函数调用时，不要加`()`,但可以加`{ }`
有参：有参构造函数
构成 构造函数的重载（类中可以有多个构造函数）
有多个构造函数，通过形参列表来判断使用哪个构造函数
把一些初始化的操作放在构造函数内部

注意：
如果类中没有构造函数，编译器会帮我们生成一个默认无参的构造函数
如果类中有任意的构造函数，编译器就不会生成默认无参的构造函数
	可以显式的把无参构造函数写出来
	也可以`MyClass() = default`

构造函数的初始化
	使用初始化列表的形式，对数据成员初始化
	对多个数据成员初始化，中间加逗号
	初始化顺序：与声明数据成员的顺序相关，与初始化列表的顺序无关
```c++
Point (int x ,int y) : m_x(x),m_y(y)

//m_x(x)  //()中写要初始化的值
```

对象的大小：
与类中数据成员的数据类型相关 
空对象的大小是 1 个字节
特殊情况：内存对齐
	内存对齐会按照类中最大的数据成员的整数倍对齐
	与数据成员的顺序有关
	有数组，除了数组之外，最大成员的整数倍
```c++
class D{
	int m_d1;     //4
	int m_d2;     //4
	double m_d3;  //8
};  //size = 16
class C{
	int m_c1;      //4
	double m_c2;   //8
	int m_c3;      //4
};  //size = 24
```

##### 析构函数
特殊的成员函数，对象销毁的时候会自动调用
一般情况，让析构函数自动执行。系统默认会加一个析构函数，没涉及资源一般不要写析构函数
调用时机（生命周期）：
	局部对象：函数执行完，栈帧销毁时会调用析构函数
	全局对象：程序结束时会调用析构函数
	静态对象：程序结束时会调用析构函数
	堆上的对象：需要手动delete指针，才会调用析构函数

![[堆上的对象.png]]

```c++
~ 类名 (){
	析构函数体
	资源释放的操作  //先判断是否有资源需要释放
}
```
资源：内存资源、网络资源、文件资源

堆上的对象
```c++
//computer 类
Computer {
public:
	//构造函数
	Computer(const char *brand,int price) 
	: m_brand (new char[strlen(brand)+1]{})
	,m_price(price)
	{
		cout << "constructor" << endl;
		strcpy(m_brand,brand);
	}
	void print(){
		cout << m_brand << " " <<m_price<<endl;
	}
	//析构函数
	~Computer()
	{
		cout << "~Computer()" << endl;
		//先判断指针是否为空
		//如果不为空就执行delete
		//将指针设置为nullptr
		if(m_brand){
			delete [] m_brand;
			m_brand = nullptr;
		}
	}
private:
	char * m_brand;
	int m_price;
};

void test(){
	//申请一个堆上的对象
	Computer *p = new Computer{"xiaomi",1999};
	//delete指针时，会调用析构函数
	delete p;
	p = nullptr;
}
//使用堆上的对象 使用 -> 指针
```


构造函数与析构函数的调用顺序
```c++
class Sample 
{
	int i;
public:
	Sample();
	Sample(int val);
	void Display();
	~Sample();
};
//在类外定义无参构造函数
Sample::Sample() 
{
    cout << "Constructor1" << endl;
    i=0;
}
//在类外定义一个形参构造函数
Sample::Sample(int val) 
{
    cout << "Constructor2" << endl;
    i=val;
}
//在类外定义函数
void Sample::Display() 
{
    cout << "i=" << i << endl;
}
//在类外定义析构函数
Sample::~Sample() 
{
    cout << "Destructor" << endl;
}

int main() 
{
	//a调用无参构造函数，b调用有参构造函数
    Sample a, b(10);
    //a、b调用display函数打印i的值
    a.Display();
    b.Display();
	 
    return 0;
}

构造函数的顺序
先是a调用无参构造函数，b调用有一个形参的构造函数
接着是a打印i=0，b打印i=10
析构函数与构造函数的调用相反，先调用b的析构函数再调用a的析构函数
```

析构函数的调用顺序
```c++
//设已经有A,B,C,D 4个类的定义，程序中A,B,C,D析构函数调用顺序为？

C c;
int main()
{
    A *pa=new A();
    B b;
    static D d;
    delete pa;
    return 0;
}
-----------------------
c是全局对象
A是堆对象
b是局部对象
d是静态变量
//构造顺序：
c 全局对象，在main函数前构造
a是堆对象，在new时构造
b是局部，在进入作用域时构造
d是静态局部，第一次执行到此处时构造

//析构顺序，与构造相反
a，delete调用a的析构函数，main结束前
main结束，调用b的析构函数
程序结束，调用d的析构函数
全局清理，调用c的析构函数
a-b-d-c
```
