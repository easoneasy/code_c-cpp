##### **问题**：形参中，为什么要使用const、为什么要使用&（引用）
	使用const：
		左值、右值的问题，非const的引用不能绑定右值
		创建对象时，不知道赋值的是左值还是右值
	使用&（引用）：
		避免复制
		避免递归调用，不加引用，复制对象会一直调用拷贝构造函数，直到栈溢出

###### 左值与右值
左值：可以取地址的值
	有名字的变量、有名字的对象、字符串常量等
右值：不能取地址的值
	匿名的对象、临时的变量/对象、字面值常量

```c++
//左值
int a = 1;
&a;
Point pt{1,2};
&pt;
&"hello"

//右值
&Point{3,4}; //error
int b = 1;
int c = 2;
&(b+c);  //error
&100;    //error
```

```c++
int num = 1;
int & ref = num;   //correct 非const的引用能绑定左值

int & ref = 1;   //error 非const的引用不能绑定右值

const的引用可以绑定左值和右值
```

###### this
所有的成员函数中，形参列表中都有一个隐含的参数 this
this本质是一个指针，常量指针
指向的是==当前对象==
哪个对象调用这个函数，哪个对象就是当前对象
非静态成员函数才有this，指向当前对象

深拷贝规范写法：
	自赋值判断
	回收当前对象指针原来申请的空间
	深拷贝操作
	返回当前对象 * this
```c++
Computer & operator = (const Computer &rhs)
{
	//自赋值判断
	if (this != &rhs)
	{
	//回收原本的空间
	delete [] m_brand;
	m_brand = nullptr;
	//深拷贝，更改指针指向的位置
	this->m_brand = new char[strlen(rhs.m_brand)+1]{};
	strcpy(m_brand,rhs.m_brand);
	this->m_price = rhs.m_price;
	}
	//返回当前对象
	return *this;
}
```

三合成原则：
	拷贝构造、析构、赋值运算符函数 一起手动定义（使用new动态分配时）

##### 特殊的数据成员
常量的const数据成员
		必须要在初始化列表中初始化，如果类中有多个构造函数，所有的构造函数中都要进行初始化操作
		C++11之后，可以直接给常量数据成员赋值
引用数据成员
		必须要在初始化列表中初始化
		所绑定的变量或对象声明周期大于等于该对象
对象数据成员
		在初始化列表中初始化
		执行哪个类的顺序和声明成员的顺序有关
静态数据成员
		使用static修饰类中普通成员
		静态数据成员不依赖对象，依赖类
		不占据对象的内存大小
		静态数据成员通过类名作用域来访问（规范，可以看出是静态数据成员）,也可以使用对象.访问(看不出来成员的类型)
		静态数据成员被所有的对象**共享**
		需要在类外初始化，不能用初始化列表初始化静态数据成员

class Distance	
{

	//构造函数声明
	Distance(Point xp1, Point xp2);

	{
		return dist;
	}
private:	
	Point p1,p2;
	double dist;	
};
//Distance类的构造函数
Distance::Distance(Point xp1, Point xp2)
: p1(xp1)   //形参拷贝给实参，调用拷贝构造函数
, p2(xp2)
{
	cout << "Distance构造函数被调用" << endl;
	double x = double(p1.GetX() - p2.GetX());
	double y = double(p1.GetY() - p2.GetY());
	dist = sqrt(x * x + y * y);
}

	Point myp1(1,1), myp2(4,5);
	Distance myd(myp1, myp2);
	//myp1、myp2给形参xp1、xp2赋值，调用两次拷贝构造函数
	//xp1、xp2形参拷贝给实参p1、p2，调用拷贝构造函数
	cout << "The distance is:" ;
	cout << myd.GetDis() << endl;
	
	return 0;
}
