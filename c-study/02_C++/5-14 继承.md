#### 1. 虚表（`vtbl`）的创建

- 只要一个类中包含了 `virtual` 关键字修饰的成员函数，编译器就会为这个类创建一张**虚函数表**。
    
- 虚表本质上是一个**函数指针数组**，里面按顺序存放着该类中所有虚函数的入口地址。
    
- **子类的虚表生成逻辑**：
    1. 首先拷贝一份父类的虚表。
    
    2. 如果子类重写了父类的某个虚表函数，子类虚表中对应的函数地址就会被覆盖（Override）为子类自己的函数地址。
    
    3. 如果子类新增了虚函数，其地址会被追加到虚表的末尾。

#### 2. 虚指针（`vptr`）的注入

- 当一个类拥有虚表时，编译器会自动在这个类的对象内存布局的最前面（通常是头部）隐式添加一个指针，称为 **虚指针 `vptr`**。
    
- 当对象被实例化时，构造函数负责将这个 `vptr` 指向该类对应的虚表。
    
- **注意**：虚表是属于**类**的（同一个类的所有对象共用一张虚表），而虚指针是属于**对象**的（每个对象都有自己的 `vptr`）。

```C++
class Animal {
public:
    virtual void speak() { cout << "Animal speak"; }
};

class Dog : public Animal {
public:
    void speak() override { cout << "Dog bark"; } // 重写
};

Animal* p = new Dog();
p->speak();
```

- **寻址**：由于 `speak()` 是虚函数，编译器编译 `p->speak()` 时不会直接写死 `Animal::speak` 的地址。它会生成一段寻找逻辑：
    
    - 第一步：通过指针 `p` 找到 `Dog` 对象的内存。
        
    - 第二步：取出对象头部的虚指针 `vptr`。
        
    - 第三步：通过 `vptr` 找到 `Dog` 类的虚表 `vtbl`。
        
- **调用**：在 `Dog` 的虚表中，原本属于 `Animal::speak` 的位置已经被替换成了 `Dog::speak` 的地址。
    
- **结果**：程序最终成功跳转到 `Dog::speak` 的代码段执行，打印出 "Dog bark"。


- **多态的表现**：父类指针指向子类对象，调用同名虚函数，表现出子类的行为。
    
- **多态的本质**：通过对象内部的 **`vptr` ➔ `vtbl` ➔ 实际函数地址** 进行动态间接调用。

什么是纯虚函数？什么是抽象类？抽象类的作用是什么？

纯虚函数：用virtual  返回类型  函数名 () = 0;来声明的无实现函数

抽象类：包含纯虚函数的类。只能作父类，不能实例化。

抽象类的作用：作为接口、代码复用


**重载（Overload）**、**隐藏（Hiding / Redefine）** 和**覆盖（Override / 重写)**

| **特性**            | **重载 (Overload)** | **隐藏 (Hiding)**     | **覆盖 (Override)**     |
| ----------------- | ----------------- | ------------------- | --------------------- |
| **发生区域**          | **同一个类**内部        | **基类与派生类**之间        | **基类与派生类**之间          |
| **函数名称**          | 必须相同              | 必须相同                | 必须相同                  |
| **参数列表**          | **必须不同**          | 是否相同都可以             | **必须相同**              |
| **`virtual` 关键字** | 无关                | 基类函数**无** `virtual` | 基类函数**必须有** `virtual` |
| **绑定机制**          | 静态绑定（编译期）         | 静态绑定（编译期）           | **动态绑定（运行期）**         |
| **多态表现**          | 不表现多态             | 不表现多态               | **表现动态多态**            |

==重载==是指在**同一个作用域内**，允许存在多个**同名但参数列表不同**的函数。
- **边界**：必须在同一个类中（或者同一个全局作用域中）。
    
- **条件**：函数名相同，但参数个数、参数类型或参数顺序必须不同（返回值类型不能作为重载的依据）。
    
- **原理**：静态绑定。编译器在编译期根据传入的参数类型决定调用哪个函数。

==隐藏==是指在**不同的作用域中**（通常是派生类和基类），子类定义了一个与父类**同名**的函数。此时，父类的同名函数在子类的作用域中就会被“遮蔽”掉。
- **边界**：分别位于基类和派生类中。
    
- **条件**：只要**函数名相同**，无论参数列表是否相同。如果参数相同，父类函数被隐藏；如果参数不同，父类所有同名重载函数也统统被隐藏（不会在子类中构成重载）。
    
- **特殊点**：父类函数**不能**有 `virtual` 关键字（如果有 `virtual` 且参数相同，那就变成覆盖了）。

==覆盖==是实现**动态多态**的核心。它是指子类**重新实现**了父类中用 `virtual` 声明的虚函数。

- **边界**：分别位于基类和派生类中。
    
- **条件**：
    1. 父类函数必须有 **`virtual`** 关键字。
        
    2. 函数名、参数列表、返回值类型（协变除外）必须与父类完全**一模一样**。
        
- **原理**：动态绑定。通过我们前面讲过的虚表（`vtbl`）机制，在运行期根据对象的实际类型进行调用。


###### 析构函数设置为虚函数
```c++
class Father
{
public:
	Father()
	:m_f(new int{1})
	{
		cout << "Father constructor" << endl;
	}
	~Father()
	{
		cout << "Father destructor" << endl;
		delete m_f;
	}
	int *m_f;
};

class Son : public Father
{
public:
	Son()
	:m_f(new int{2})
	{
		cout << "Son constructor" << endl;
	}
	~Son()
	{
		cout << "Son destructor" << endl;
		delete m_s;
	}
	int *m_s;
};

//栈对象
Son son;
//对象销毁时，调用子类的析构函数，再调用父类的析构函数

//堆对象
Son *s = new Son{};
Father *f = new Son{};
delete f;  //调用析构函数
//只调用了父类的析构函数，不会调用子类的析构函数
//解决方法：在父类析构函数前加virtual关键字
```
析构函数:destructor
加了virtual关键字的析构函数：dtor
