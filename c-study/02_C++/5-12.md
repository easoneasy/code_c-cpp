std::string的写时复制

```c++
//无参构造
CowString()
:m_pStr(new char[4+1]{}+4)   //让指针向右偏移4个位置,指向字符位置
{
	cout << "CowString" << endl;
	//初始化引用计数器为1
	*(int *)(m_pStr - 4) = 1;
}
//有参构造
CowString(const char *pStr)
:m_pStr(new char[4 + strlen(pStr) + 1]{} +4)
{
	//初始化引用计数器为1
	*(int *)(m_pStr - 4) = 1;
	strcpy(m_pStr,pStr)
}
```

关联式容器：set、map
set：底层结构使用的是红黑树

特点：存储单列数据，一个一个的数据，1，2，3，4，5
存储数据的特点：有序，默认按照升序排列
存储的数据不能重复

使用场景：
	去重
	排序

存储数据时，像vector，需要指明数据的类型是什么
存储自定义类型时，需要排序，重载`<` 
```c++
//无参构造
set<int> box1;
//初始化列表的方式
set<int> box2{4,3,5,1,2};
//迭代器方式
set<int> box3{box2.begin(),box2.end()};
//拷贝构造
set<int> box4 {box3};
```

map容器
存储的是双列数据（一对一对）
key-value数据，键值对数据
属性名 = 属性值

底层是红黑树
key不能重复,value可以重复
按照key升序进行排序
```c++
//无参构造
map<int,string> m1;
//初始化列表构建   
map<int,string> m2{
	pair<int,string>{2,"zs"},
	pair<int,string>{3,"ls"},
};
//简写
map<int,string> m2{
	{2,"zx"},
	{3,"yy"}
};
map<int,string> m2{
	std::make_pair(2,"zs"),
	std::make_pair(3,"ls")
};
//迭代器方式
map<int,string> m5{m2.begin(),m2.end()};
//拷贝构造函数构建
map<int,stirng>m6{m2};
```
